Qué está implementado

Laravel 13 / Blade, migraciones, login y logout, MFA TOTP y recuperación, RBAC en servidor, revocación de sesiones, CSRF, límites, cabeceras de seguridad, auditoría, medios privados reprocesados, panel, consulta de borradores e instalador privado para Terminal/Cron de staging.

Las pruebas locales usaron PHP 8.4 y MariaDB. Las dependencias están fijadas para PHP 8.3; CI PHP 8.3/MySQL 8 aún no ejecutado. Hito 1 pendiente de cierre.

Qué falta

Web corporativa definitiva, CMS visual integral, administración del catálogo, carrito/preventas, bandejas/notificaciones, blog y operación completa: hitos 2–7. SMTP real, staging cPanel, backups y aprobación del dueño pendientes.

Probar el backend antes de subir

Necesitas el proyecto PHP en un entorno de desarrollo con PHP 8.3+, MySQL/MariaDB y Composer. Solo la carpeta public/ se sirve al navegador. Configura una base nueva y privada en .env.

composer install --no-interaction --prefer-dist
php artisan key:generate
php artisan migrate --seed
npm ci
npm run build
php artisan jmac:verify-empty
php artisan jmac:admin tu-correo@tu-dominio.com
php artisan serve

El comando de administrador pide una contraseña privada. El primer acceso exige MFA. Sigue el README del proyecto para configurar .env y desarrollo local. No existen claves o cuentas predeterminadas.

Este HTML no tiene un formulario de acceso simulado. Para comprobar seguridad, guardado y subidas debes usar la aplicación PHP real.
